# FinancialAuthority demo

The same screens as the app, over a synthetic household. Every number came out of the engine when the demo was captured; nothing here is real, and changes are not kept. The app itself lives at github.com/AES256Afro/FinancialAuthority.

This repository holds only the built demo, served at demo.cybercard.net. It is regenerated from the app with `scripts/publish-demo.sh` there.
